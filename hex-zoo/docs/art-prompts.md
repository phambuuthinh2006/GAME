# Art production prompts and manifest hand-off

All visuals in the running slice are deliberately clean placeholders. Do not submit this build until the final art is imported, checked on real devices and reviewed beside the best competitor. These are original asset directions; no competitor characters, screenshots or layouts are references.

## Generate and import

Start with **moss-marten**, **dune-fennec**, **brook-otter**, **velvet-genet** (one per family), then **keeper-mira**, **board-meadow**, **menu-background** and **logo**. Check style consistency and 52–80 px tile readability before producing the other portraits. Generate the covers last, after the title is cleared and gameplay art is final.

Each heading below is the exact input basename. Save one image as `art-in/<id>.png` (JPG or WebP is also accepted). All paths are relative to `hex-zoo/`. Do not bake names or scores into portraits; the game draws those as readable text.

Install Python 3.11+ and Pillow, then run:

```sh
python3 -m venv .venv-art
.venv-art/bin/python -m pip install Pillow
.venv-art/bin/python tools/import-art.py --self-test
.venv-art/bin/python tools/import-art.py
npm run build:crazygames
```

If your machine has uv, a workspace-local dependency install also works:

```sh
uv pip install --target artifacts/pillow Pillow
PYTHONPATH=artifacts/pillow uv run --no-project --python 3.11 python tools/import-art.py --self-test
PYTHONPATH=artifacts/pillow uv run --no-project --python 3.11 python tools/import-art.py
```

The importer removes the solid green from cutouts with soft alpha and spill suppression, trims the content, adds 8% breathing room, pads to square, resizes, and writes a palette PNG into `public/art/`. Scenes and covers retain their target aspect ratio and use a centered crop rather than green removal. Missing inputs are skipped and leave `path: null` in `public/art-manifest.json`, so the existing placeholder continues. Empty/all-green images fail clearly.

The manifest is the one place to swap each image. The importer updates its `path`; restart Vite after importing. `getAsset()` resolves paths with `new URL(path, document.baseURI).href` to work from a sub-path and from JS CSS properties. Remove an imported image by setting only that manifest entry’s `path` back to `null`. Keep original inputs locally. Avoid green animal body markings: a chroma-key workflow cannot distinguish those from the background.

The listed dimensions are final outputs; source images can be larger with the same framing. Cover entries are marketing-only; the build automatically excludes their files from dist-crazygames/ after import. Verify the rebuilt initial download remains under 5 MB.
